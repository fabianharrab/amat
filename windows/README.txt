Amat - Angewandte Mathematik / Applied mathematics
==================================================

Start: double-click amat.exe. Nothing needs to be installed; keep the
files in this folder together.

The first time, Windows may say "Windows protected your PC" because the
program isn't signed. Click "More info", then "Run anyway".

The app uses the Windows display language: German Windows shows German.
Your inputs are saved automatically in %APPDATA%\amat.

Pages: 1-9 and 0 switch pages, ? shows all shortcuts, Ctrl+O opens a data
file (CSV/TXT like np.loadtxt, or WAV), Ctrl+E exports the plot as PNG or
SVG. Every result has the matching Python code in the "Python" tab.
