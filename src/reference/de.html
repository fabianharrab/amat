Theorie & Spickzettel

Kurz und auf den Punkt, passend zu den Repetitionsaufgaben. Rechnen kannst du alles auf den anderen Seiten; hier stehen die Regeln.

1 · Arrays / NumPy

  • np.arange(start, stop, step): stop gehört nicht dazu. np.arange(0, 10, 2) → [0 2 4 6 8] (Ganzzahlen).
  • np.linspace(start, stop, num): stop gehört dazu, Anzahl Werte statt Schritt, immer Float. np.linspace(0, 10, 6) → [0. 2. 4. 6. 8. 10.].
  • Konstanter Array [5. 5. … 5.] (8×): np.zeros(8) + 5, np.ones(8) * 5, np.linspace(5, 5, 8), np.full(8, 5.). np.arange(5, 5, 0) ist falsch (Schritt 0).
  • Dimension (.ndim) = Anzahl öffnender Klammern am Anfang: [[[ → 3. .shape zählt die Elemente pro Ebene, z. B. (2, 3, 4).
  • Rechnen ist elementweise: np.array([1, 2, 3]) * 2 → [2 4 6]. Eine Liste [1, 2, 3] * 2 wiederholt sich → [1, 2, 3, 1, 2, 3]; liste / 1000 gibt einen Fehler → Array verwenden oder [ti / 1000 for ti in t_ms].
  • Indizierung a[zeile, spalte], beginnt bei 0. Mittlere Spalte: a[:, 1] oder a.T[1]. Zeile: a[1] = a[1, :]. Letztes Element: a[-1].
  • np.round(np.exp([1., 2., 3.]), 2) → [ 2.72 7.39 20.09].
  • np.loadtxt(datei, delimiter=';', skiprows=1): skiprows = Anzahl Kopfzeilen (Zeilen mit # werden automatisch übersprungen), delimiter = Trennzeichen (Standard: Leerzeichen/Tab). Spalten: data[:, 0]. Die App zeigt dir beides an, wenn du die Datei öffnest (Python-Tab).

2 · Matplotlib

  • Formatstring '[Marker][Linie][Farbe]': 'r--' = rot gestrichelt, 'ko' = schwarze Punkte, 'b.-'. Gleichwertig: color='red', linestyle='--'. 'red--' ist ungültig.
  • fig, axs = plt.subplots(nrows=2, ncols=3) → axs[zeile, spalte] ab 0: unten Mitte = axs[1, 1].plot(…). Bei nur einer Spalte: axs[0], axs[1].
  • label='…' benennt eine Kurve; plt.legend() zeigt dann die Legende, ohne den Text nochmals anzugeben.
  • Log-Achse: ax.set_yscale('log'). Gitter: ax.grid(). Gleiche Skalierung: plt.axis('equal').
  • Speichern vor plt.show(): plt.savefig('bild.svg') (Format aus der Endung). In der App: Ctrl+E, Dateiname auf .svg.

3 · Vektorrechnung

  • Polar → kartesisch: p = [r·cos φ, r·sin φ]. Betrag 9, 30° → [7.794, 4.5] (App: Vektor 9@30).
  • Betrag np.linalg.norm(p), Phase immer np.arctan2(y, x) (y zuerst!). [-4, 3] → Betrag 5, Phase 143.13° (arctan allein gäbe falsch −36.87°).
  • Skalarprodukt a·b = axbx + ayby = |a||b|cos φ: > 0 spitzer Winkel, = 0 senkrecht, < 0 stumpfer Winkel. Beispiel [1, 1.1]·[−0.1, −1] = −1.2 < 0.
  • Kreuzprodukt nur 3D, steht senkrecht auf beiden, Betrag = Parallelogrammfläche.
  • Rotationsmatrix R(φ) = [[cos φ, −sin φ], [sin φ, cos φ]]: quadratisch, Spalten haben Länge 1 und stehen senkrecht (RᵀR = I), det R = 1, und es gilt cos² + sin² = 1 (z. B. 0.5403² + 0.8415² = 1). Die App prüft das im Matrix-Feld.
  • Vektor drehen (aktiv): p' = R @ p. Koordinaten im gedrehten System (passiv): p' = R.T @ p. Gedreht und verschoben: p' = R.T @ (p − t). Drehen dann verschieben: R @ p + t.
  • Roboterarm mit Drehwinkel φ und Länge L: Greifer r = R(φ) @ [L, 0] = L·[cos φ, sin φ].

4 · Statistik & Messunsicherheit

  • Messergebnis = Mittelwert. Standardabweichung s = x.std(ddof=1) (durch N−1). Beispiel [3.47, 3.51, 3.48] → x̄ = 3.4867, s = 0.0208.
  • Einzelwerte (Normalverteilung): ≈ 68 % in x̄ ± s, ≈ 95 % in x̄ ± 2s, ≈ 99.7 % in x̄ ± 3s.
  • Konfidenzintervall (95 %) des Mittelwertes: x̄ ± 2·s/√N. N = 100, s = 2.8 g → 248.7 ± 0.56 g. Bedeutung: Das Intervall enthält den (unbekannten) wahren Wert mit 95 % Wahrscheinlichkeit; würde man die Messreihe oft wiederholen, enthielten etwa 95 % der so berechneten Intervalle den wahren Wert. Es wird mit mehr Messungen schmaler (∝ 1/√N), die Streuung der Einzelwerte (s) aber nicht.
  • Unsicherheit: u₁ = s/√N; weitere Beiträge quadratisch addieren u = √(u₁² + u₂² + …); Toleranz ±a → u = a/√3; erweitert U = k·u (k = 2 ≙ 95 %).
  • Angabe: U auf 2 signifikante Stellen runden, Ergebnis auf dieselbe Stelle, k nennen: I = 0.857 ± 0.014 A (k = 2).
  • Fehlerfortpflanzung: u_y = √Σ(∂y/∂xᵢ · uᵢ)² (App: Seite Fehlerfortpflanzung, Ableitungen werden angezeigt).

5 · Signale / SciPy

  • y(t) = A·cos(2πft + φ) + y₀: A Amplitude, f Frequenz, Periode T = 1/f, Offset y₀. Phase φ verschiebt um Δt = −φ/(2πf): φ = −60° → Kurve um 60/360·T nach rechts. Beispiel A = 2, f = 20 Hz, φ = −60°: T = 50 ms, Maximum bei t = 8.33 ms, y(0) = 2·cos(−60°) = 1.
  • Funktion aus einem Plot ablesen: Offset = (max + min)/2, Amplitude = (max − min)/2, T = Abstand zweier Maxima, f = 1/T, Phase aus der Lage des ersten Maximums t_max: φ = −2π·f·t_max (Kosinusform). Prüfen: in der App auf „Funktionen“ zeichnen.
  • Filterwahl: Tiefpass lässt tiefe Frequenzen durch (glätten, Rauschen weg), Hochpass hohe (Trend/Offset weg). Um nur die höchste Komponente zu behalten: Grenzfrequenz zwischen der zweithöchsten und der höchsten Frequenz wählen. Medianfilter gegen Ausreisser, Savitzky-Golay glättet formtreu.
  • Lineare Interpolation zwischen (t₁, y₁) und (t₂, y₂): y = y₁ + (y₂ − y₁)·(t − t₁)/(t₂ − t₁); die Ableitung dort ist die Steigung (y₂ − y₁)/(t₂ − t₁) mit Einheit [y]/[t] (z. B. mm/s). App: „Ausgleich“, Modell lineare Interpolation, „Auswerten bei“.
  • Integrieren: Position = Fläche unter der Geschwindigkeit, x(t) = x₀ + ∫v dt. Konstantes v → Gerade, linear steigendes v → Parabel, v = 0 → x bleibt konstant. Ableiten: Steigung; Ableiten verstärkt Rauschen → vorher glätten.
  • Abtastung: fs = 1/Δt, t = np.arange(N)/fs, Messdauer N/fs.

6 · Frequenzanalyse / FFT

  • Abtasttheorem: Die Abtastfrequenz muss mehr als doppelt so gross sein wie die höchste Frequenz im Signal, fs > 2·f_max. Sonst entsteht Aliasing: höhere Frequenzen erscheinen gespiegelt als falsche tiefe Frequenz (25 Hz mit fs = 30 Hz → 5 Hz). Folgen: Das Spektrum reicht nur bis fs/2 (Nyquist); fs genügend hoch wählen bzw. vor dem Abtasten tiefpassfiltern.
  • f_max = fs/2, Auflösung Δf = 1/T_mess = fs/N. fs = 0.6 kHz, 1 min → f_max = 300 Hz, Δf = 0.017 Hz.
  • Amplitudenspektrum: Peak bei 0 Hz = Gleichanteil (Mittelwert); jede Sinus-/Kosinuskomponente gibt einen Peak an ihrer Frequenz mit Höhe = ihre Amplitude (einseitig, A[1:] *= 2). Rechteck: ungerade Harmonische, Höhe 4/π·A/n. Rauschen hebt den „Boden“ an.
  • Skizze: Frequenzachse von 0 bis fs/2 beschriften (Hz), Amplitudenachse in der Signaleinheit; Peaks bei den Frequenzen mit den Amplituden einzeichnen. Prüfen: „Spektrum“ → Formel, fs und Dauer eintragen.
  • Nicht ganzzahlige Periodenzahl → Leakage (verschmierte Peaks) → Fensterfunktion (z. B. tukey, hann), Offset vorher entfernen: y_w = w*(y − y.mean()) + y.mean().
  • Peaks über einer Schwelle: peaks, _ = signal.find_peaks(A, height=5), np.round(f[peaks], 3). Index 0 (DC) wird nie als Peak gefunden.

7 · Teil B: welche Seite?

  • Druckpulsation (FFT): Seite Spektrum → Datei öffnen, Zeitspalte wählen (fs wird aus t berechnet), Faktor 1000 (bar → mbar), log. Amplitudenachse, „nur Peaks mit Amplitude ≥ 5“. Das Python-Tab liefert den Code inkl. Subplots.
  • Rollende Kugel: Seite Signal → fs = 1/2e-3, Schritt Savitzky-Golay oder Tiefpass (glätten), dann Ableitung d/dt → Geschwindigkeit, nochmals d/dt → Beschleunigung a. Oder Seite Ausgleich: Polynom Grad 2 an x(t), dann a = 2·a₂. Neigung: rutschend a = g·sin α → α = arcsin(a/g); rollende Vollkugel a = 5/7·g·sin α → α = arcsin(7a/(5g)). Begründen, welches Modell du annimmst.
  • Roboterarm: Seite Arrays → Datei öffnen, Spalten t, phi, delta_r, neue Spalten L = 0.6 + delta_r, x = L*cos(phi), y = L*sin(phi), x-Achse x, y-Achse y, Vektor zu Zeile 0 = Startstellung; Export als .svg.
