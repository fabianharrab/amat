Theory & cheat sheet

Short and to the point, matching the review exercises. Every calculation can be done on the other pages; the rules are here.

1 · Arrays / NumPy

  • np.arange(start, stop, step): stop is excluded. np.arange(0, 10, 2) → [0 2 4 6 8] (integers).
  • np.linspace(start, stop, num): stop is included, a count instead of a step, always floats. np.linspace(0, 10, 6) → [0. 2. 4. 6. 8. 10.].
  • Constant array [5. 5. … 5.] (8×): np.zeros(8) + 5, np.ones(8) * 5, np.linspace(5, 5, 8), np.full(8, 5.). np.arange(5, 5, 0) is wrong (step 0).
  • Dimension (.ndim) = number of opening brackets at the start: [[[ → 3. .shape counts the elements per level, e.g. (2, 3, 4).
  • Arithmetic is element-wise: np.array([1, 2, 3]) * 2 → [2 4 6]. A list [1, 2, 3] * 2 repeats → [1, 2, 3, 1, 2, 3]; list / 1000 raises an error → use an array or [ti / 1000 for ti in t_ms].
  • Indexing a[row, column], starting at 0. Middle column: a[:, 1] or a.T[1]. Row: a[1] = a[1, :]. Last element: a[-1].
  • np.round(np.exp([1., 2., 3.]), 2) → [ 2.72 7.39 20.09].
  • np.loadtxt(file, delimiter=';', skiprows=1): skiprows = number of header lines (lines starting with # are skipped anyway), delimiter = separator (default: spaces/tabs). Columns: data[:, 0]. The app shows both when you open the file (Python tab).

2 · Matplotlib

  • Format string '[marker][line][color]': 'r--' = red dashed, 'ko' = black dots, 'b.-'. Equivalent: color='red', linestyle='--'. 'red--' is invalid.
  • fig, axs = plt.subplots(nrows=2, ncols=3) → axs[row, column] from 0: bottom middle = axs[1, 1].plot(…). With a single column: axs[0], axs[1].
  • label='…' names a curve; plt.legend() then shows the legend without repeating the text.
  • Log axis: ax.set_yscale('log'). Grid: ax.grid(). Equal scaling: plt.axis('equal').
  • Save before plt.show(): plt.savefig('figure.svg') (format from the extension). In the app: Ctrl+E, file name ending in .svg.

3 · Vectors

  • Polar → Cartesian: p = [r·cos φ, r·sin φ]. Magnitude 9 at 30° → [7.794, 4.5] (app: vector 9@30).
  • Magnitude np.linalg.norm(p), phase always np.arctan2(y, x) (y first!). [-4, 3] → magnitude 5, phase 143.13° (arctan alone wrongly gives −36.87°).
  • Dot product a·b = axbx + ayby = |a||b|cos φ: > 0 acute angle, = 0 perpendicular, < 0 obtuse. Example [1, 1.1]·[−0.1, −1] = −1.2 < 0.
  • Cross product only in 3D, perpendicular to both, magnitude = parallelogram area.
  • Rotation matrix R(φ) = [[cos φ, −sin φ], [sin φ, cos φ]]: square, columns of length 1 and perpendicular (RᵀR = I), det R = 1, and cos² + sin² = 1 (e.g. 0.5403² + 0.8415² = 1). The app checks this in the matrix field.
  • Rotate a vector (active): p' = R @ p. Coordinates in a rotated system (passive): p' = R.T @ p. Rotated and shifted: p' = R.T @ (p − t). Rotate then shift: R @ p + t.
  • Robot arm with angle φ and length L: gripper r = R(φ) @ [L, 0] = L·[cos φ, sin φ].

4 · Statistics & measurement uncertainty

  • The result is the mean. Standard deviation s = x.std(ddof=1) (divide by N−1). Example [3.47, 3.51, 3.48] → x̄ = 3.4867, s = 0.0208.
  • Single values (normal distribution): ≈ 68 % within x̄ ± s, ≈ 95 % within x̄ ± 2s, ≈ 99.7 % within x̄ ± 3s.
  • Confidence interval (95 %) of the mean: x̄ ± 2·s/√N. N = 100, s = 2.8 g → 248.7 ± 0.56 g. Meaning: the interval contains the (unknown) true value with 95 % probability; if the series were repeated many times, about 95 % of the intervals computed this way would contain the true value. More measurements make it narrower (∝ 1/√N); the scatter of single values (s) does not shrink.
  • Uncertainty: u₁ = s/√N; add further contributions in quadrature u = √(u₁² + u₂² + …); tolerance ±a → u = a/√3; expanded U = k·u (k = 2 ≙ 95 %).
  • Reporting: round U to 2 significant digits, the result to the same place, and state k: I = 0.857 ± 0.014 A (k = 2).
  • Error propagation: u_y = √Σ(∂y/∂xᵢ · uᵢ)² (app: Error propagation page, derivatives shown).

5 · Signals / SciPy

  • y(t) = A·cos(2πft + φ) + y₀: A amplitude, f frequency, period T = 1/f, offset y₀. The phase shifts by Δt = −φ/(2πf): φ = −60° → curve moves 60/360·T to the right. Example A = 2, f = 20 Hz, φ = −60°: T = 50 ms, maximum at t = 8.33 ms, y(0) = 2·cos(−60°) = 1.
  • Reading a function from a plot: offset = (max + min)/2, amplitude = (max − min)/2, T = distance between two maxima, f = 1/T, phase from the first maximum t_max: φ = −2π·f·t_max (cosine form). Check by plotting it on “Functions”.
  • Filters: a low-pass keeps low frequencies (smoothing, removes noise), a high-pass keeps high ones (removes trend/offset). To keep only the highest component, put the cutoff between the second-highest and the highest frequency. Median filter against outliers; Savitzky–Golay smooths while keeping the shape.
  • Linear interpolation between (t₁, y₁) and (t₂, y₂): y = y₁ + (y₂ − y₁)·(t − t₁)/(t₂ − t₁); the derivative there is the slope (y₂ − y₁)/(t₂ − t₁) with unit [y]/[t] (e.g. mm/s). App: “Fit”, model linear interpolation, “Evaluate at”.
  • Integration: position = area under the velocity, x(t) = x₀ + ∫v dt. Constant v → straight line, linearly rising v → parabola, v = 0 → x stays constant. Differentiation = slope; it amplifies noise → smooth first.
  • Sampling: fs = 1/Δt, t = np.arange(N)/fs, duration N/fs.

6 · Frequency analysis / FFT

  • Sampling theorem: the sampling rate must be more than twice the highest frequency in the signal, fs > 2·f_max. Otherwise aliasing: higher frequencies show up folded as a false low frequency (25 Hz sampled at 30 Hz → 5 Hz). Consequences: the spectrum only reaches fs/2 (Nyquist); choose fs high enough or low-pass filter before sampling.
  • f_max = fs/2, resolution Δf = 1/T_meas = fs/N. fs = 0.6 kHz for 1 min → f_max = 300 Hz, Δf = 0.017 Hz.
  • Amplitude spectrum: the peak at 0 Hz is the DC component (mean); each sine/cosine gives a peak at its frequency with height = its amplitude (one-sided, A[1:] *= 2). Square wave: odd harmonics of height 4/π·A/n. Noise raises the floor.
  • Sketching: label the frequency axis from 0 to fs/2 (Hz), the amplitude axis in the signal's unit; draw peaks at the frequencies with the amplitudes. Check on “Spectrum” → Formula, enter fs and duration.
  • A non-integer number of periods → leakage (smeared peaks) → window function (e.g. tukey, hann), remove the offset first: y_w = w*(y − y.mean()) + y.mean().
  • Peaks above a threshold: peaks, _ = signal.find_peaks(A, height=5), np.round(f[peaks], 3). Index 0 (DC) is never reported as a peak.

7 · Part B: which page?

  • Pressure pulsation (FFT): Spectrum page → open the file, pick the time column (fs comes from t), factor 1000 (bar → mbar), log amplitude axis, “only peaks with amplitude ≥ 5”. The Python tab gives the code including the subplots.
  • Rolling ball: Signal page → fs = 1/2e-3, a Savitzky–Golay or low-pass step (smooth), then derivative d/dt → velocity, d/dt again → acceleration a. Or the Fit page: polynomial of degree 2 on x(t), then a = 2·a₂. Incline: sliding a = g·sin α → α = arcsin(a/g); rolling solid sphere a = 5/7·g·sin α → α = arcsin(7a/(5g)). Explain which model you assume.
  • Robot arm: Arrays page → open the file, columns t, phi, delta_r, new columns L = 0.6 + delta_r, x = L*cos(phi), y = L*sin(phi), x axis x, y axis y, vector to row 0 = start position; export as .svg.
